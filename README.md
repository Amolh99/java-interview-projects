# Java Interview Projects

One real-world project per interview topic. Each module uses an e-commerce order domain.

**Java 21.** Spring-based modules use Spring Boot 3.3.4.

| # | Module | Status |
|---|---|---|
| 01 | [Core Java](module-01-core-java) | Code + tests |
| 02 | [Spring Boot, REST, Kafka, Design Patterns](module-02-spring-rest-kafka) | Code + tests |
| 03 | [JVM](module-03-jvm) | Code + tests |
| 04 | [Java Collections](module-04-collections) | Code + tests |
| 05 | [Java Memory Management](module-05-memory) | Code + tests |
| 06 | [Multithreading & Concurrency](module-06-concurrency) | Code + tests |
| 07 | [Exception Handling](module-07-exceptions) | Code + tests |
| 08 | [Java 8 Interview Questions](module-08-java8-interview) | Code + tests |

Each module has its own `pom.xml` and `README.md` with interview questions.

Run a module's tests with `mvn test` inside its folder.
